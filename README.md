# Raghavendra Singh — Developer Portfolio

Personal portfolio for Raghavendra Singh, a full-stack developer, Flutter developer, and AI/ML enthusiast. The site features selected projects, project case studies, experience, skills, GitHub activity, and contact links.

## Tech stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- Framer Motion

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

## Project content

Project details and case studies are maintained in `src/data/projects.ts`. Public images, including project previews and the downloadable resume, are stored in `public/`.
